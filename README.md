# Currículo Digital

Projeto desenvolvido como atividade de revisão da disciplina de Back-end 2.

## Objetivo

Criar um currículo digital utilizando PHP, MySQL, HTML e CSS, consumindo as informações diretamente do banco de dados.

## Tecnologias

- PHP
- MySQL
- HTML5
- CSS3
- Git
